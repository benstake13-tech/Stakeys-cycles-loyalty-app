This is why "it worked before".

  `api/wallet/[action].js` (config|google|apple), `api/drive/[action].js` (list|resolve), `api/business/[action].js` (insights|status), `api/meta/[action].js` (posts|publish), `api/oauth/[action].js` (token|refresh), `api/onesignal/[action].js` (config|notify), + unchanged `api/google-business.js`. **14 → 7 functions**, real headroom.
- **Guard test** `vercel_function_budget.test.ts`: walks `api/`, ignores `_`-prefixed files/dirs, fails if > 12. Run it before adding any new `api/*.js`.
- **Lesson: never add a bare `api/*.js` file** — extend an existing `[action].js` dispatcher (or add a new one) instead. Deleting the old per-route files is mandatory (they each count).
