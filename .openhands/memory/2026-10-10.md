- A "Workshop Repair Guide launcher tile" commit `07bce07` landed on **staff-terminal only**. The other two branches were still behind, so the other surfaces were **missing the tile**.
- **Why a fast-forward cannot work here:** the three branches are NOT ancestors of each other. They hold *parallel cherry-pick equivalents* (different SHAs, same content), because `main-website`/`customer-app` contain a website-only commit `81ad3bf` that `staff-terminal` never got. So a fast-forward brings one branch up to date but carries NOTHING across to the others — the invariant that changed (SYNCING.md rule 3, matching commit sequences) is not enforced by a fast-forward. **Always propagate surface-agnostic changes with `npm run sync -- <sha>` (cherry-pick -x), never a fast-forward/merge.**
