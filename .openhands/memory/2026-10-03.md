- CREDENTIAL LESSON (cost most of this session): `GITHUB_TOKEN` here is a `ghu_` GitHub App user-to-server token — SHORT-LIVED and auto-expiring. It worked early in the session then 401'd everywhere; refresh the secret, don't re-scope it. Fine-grained PATs (`github_pat_…`) are DEFAULT-DENY and the creation UI defaults *Repository access* to "Public repositories (read-only)", which greys out write permanently (read 200 / every write 403 "Resource not accessible by personal access token", even on a public repo the user owns). Fix = classic token with `repo` scope, or fine-grained with Repository access "Only select repositories" + Contents: Read and write. Quick discriminator: `curl -s -D - -o /dev/null -H "Authorization: Bearer $T" https://api.github.com/user | grep -i x-oauth-scopes` (classic shows scopes; fine-grained shows none). Note `GET /repos/...` `permissions.push=true` is the ACCOUNT ROLE, not the token scope — misleading.
