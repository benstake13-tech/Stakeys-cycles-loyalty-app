## Gotchas learned (expensive)
- **Capacitor CLI 6 can't parse `capacitor.config.ts` on Node 24** → `TypeError: Cannot read properties of undefined (reading 'CommonJS')`. Use **`capacitor.config.json`** instead. Also: delete any stale `.ts` sibling or the CLI still picks it.
- **Android SDK install**: `/opt/android-sdk` was root-owned → `sudo mkdir` + `sudo chown` first. `sdkmanager` from `commandlinetools-linux-*_latest.zip`; `yes | sdkmanager --licenses`; install `platform-tools platforms;android-34 build-tools;34.0.0`. `android/local.properties` → `sdk.dir=/opt/android-sdk` (git-ignored).
- **AGP 8.2.1 works on JDK 21** (despite its docs saying 17) — debug APK built fine, 8.3 MB.
- **iOS cannot be built here**: Linux host, no `xcodebuild`/CocoaPods. Project is scaffolded + committed; `pod install` + Xcode build must happen on macOS. `cap sync ios` works on Linux (just skips pod install).
- Generated native artifacts are already covered by the platform `.gitignore`s (`android/.gitignore`, `ios/.gitignore`) — **do NOT commit** copied web assets (`android/app/src/main/assets/public/`, `ios/App/App/public/`) or `capacitor.config.json` under the native project; they're per-surface build output and would break `check:parity`. Left root `.gitignore` unchanged.
- Committing on `staff-terminal` also swept in pre-existing uncommitted work (error-code display-first tables, derailleur-hanger cross-reference, BLE bench). Do not push; the user hasn't asked.

## Native API fix + app icon — commit `146a831` on `staff-terminal` (not pushed)
**Root cause (confirmed in Capacitor Android source):** `WebViewLocalServer.registerUriForScheme` registers a **wildcard (`/**`) handler for the `server.hostname` authority**, so with `server.hostname=www.stakeys-cycles.co.uk` a relative `/api/...` fetch was answered from the bundled assets (404) and never hit the network. The native fetch patch (`native-bridge.js`) also skips URLs that start with `cap.getServerUrl()`, so same-origin calls could never escape.
**Fix (three parts):**
1. `src/utils/apiBase.ts` -> `apiUrl(path)`: prefixes `VITE_API_BASE_URL` when set; no-op on web/dev/tests. Wrapped every `/api/*` call site (sumup postJson/getJson, onesignal config+notify, wallet config/google/apple href, oauth token+refresh, business status+insights, meta publish+posts, drive list, google-business, featureDiagnostics probes).
2. `plugins.CapacitorHttp.enabled=true` -> request runs from native code, **bypassing CORS**. Required: the API sends **no Access-Control-Allow-Origin** and OPTIONS -> **405**.
3. Dropped `server.hostname` so the WebView origin is local (`https://localhost`) and always differs from the API origin (else Capacitor's fetch patch bypasses native routing for same-origin URLs). `android:sync`/`ios:sync` inject `cross-env VITE_API_BASE_URL=https://www.stakeys-cycles.co.uk`.
**Icon:** rendered the shield `public/logo.svg` with **headless Chromium** using the real Google fonts (Playfair Display + Plus Jakarta Sans woff2 fetched and base64-embedded) -> `assets/icon.png`, `icon-foreground.png` (transparent), `splash.png`; generated all Android/iOS icons+splashes with `npx capacitor-assets generate` (installed `@capacitor/assets`). `assets/` is the source folder. Also aligned stale `res/values/ic_launcher_background.xml` (#FFFFFF -> #050505).
**Lesson:** no local rasterizer (no rsvg/inkscape/Pillow/cairosvg) - headless chromium is the renderer of choice; `--default-background-color=00000000` for transparency; verify pixels with Pillow.
**Also fixed:** stale referral fallback domain `stakeys-cycle.co.uk` -> `www.stakeys-cycles.co.uk`.
**Verified:** web build keeps relative `/api/*` (base ''); native bundle inlines the absolute base; APK `assets/capacitor.config.json` has CapacitorHttp. Rebuilt APK `app-debug.apk` (9,446,775 B), re-served at `/tmp/apk-download/`, public download 200 byte-identical. Tests: new `api_base.test.ts` (5); full suite **153 files / 1293 tests**, the ONLY failure is the pre-existing `escooter_diagnostic.test.tsx` "no Bluetooth host" (fails at HEAD too). tsc 0.
