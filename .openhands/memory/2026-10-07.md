## Gotchas learned (expensive)
- **Capacitor CLI 6 can't parse `capacitor.config.ts` on Node 24** → `TypeError: Cannot read properties of undefined (reading 'CommonJS')`. Use **`capacitor.config.json`** instead. Also: delete any stale `.ts` sibling or the CLI still picks it.
- **Android SDK install**: `/opt/android-sdk` was root-owned → `sudo mkdir` + `sudo chown` first. `sdkmanager` from `commandlinetools-linux-*_latest.zip`; `yes | sdkmanager --licenses`; install `platform-tools platforms;android-34 build-tools;34.0.0`. `android/local.properties` → `sdk.dir=/opt/android-sdk` (git-ignored).
- **AGP 8.2.1 works on JDK 21** (despite its docs saying 17) — debug APK built fine, 8.3 MB.
- **iOS cannot be built here**: Linux host, no `xcodebuild`/CocoaPods. Project is scaffolded + committed; `pod install` + Xcode build must happen on macOS. `cap sync ios` works on Linux (just skips pod install).
- Generated native artifacts are already covered by the platform `.gitignore`s (`android/.gitignore`, `ios/.gitignore`) — **do NOT commit** copied web assets (`android/app/src/main/assets/public/`, `ios/App/App/public/`) or `capacitor.config.json` under the native project; they're per-surface build output and would break `check:parity`. Left root `.gitignore` unchanged.
- Committing on `staff-terminal` also swept in pre-existing uncommitted work (error-code display-first tables, derailleur-hanger cross-reference, BLE bench). Do not push; the user hasn't asked.
