# Assistant Gemini key configuration

The assistant calls Supabase `gemini-gateway`. It does not use the Vercel `GEMINI_API_KEY` or browser `VITE_GEMINI_API_KEY`.

In the Supabase project used by the app, open Edge Functions > Secrets and set `GEMINI_API_KEY` to your Google AI Studio key. Keep the value private. The deployed `gemini-gateway` function reads this secret. Setting a Vercel environment variable does not set a Supabase secret. Existing deployed functions receive updated secrets without rebuilding the APK.

If `gemini-gateway` is absent from Edge Functions, its source is in `supabase/functions/gemini-gateway/index.ts` and must be deployed separately. Do not disable authentication to resolve a missing-key error. A rejected key requires checking Google API restrictions and project access; a quota error requires checking quota/billing rather than replacing frontend variables.

Local corrections improve missing-key, rejected-key, quota, missing-function and session diagnostics, preserve cancellation, and replace misleading frontend setup instructions. Client-side errors show a service-unavailable reply rather than pretending it is a normal assistant answer.

Every AI feature uses server-held Supabase secrets: Shop Assistant, bike/image identification, translation, error-code assistance, promotions, growth advice, and the embedded Workshop Repair Guide hanger identifier. The repair guide calls the host gateway when embedded; its standalone page receives only public Supabase URL/anon-key configuration generated by Vite. It never receives a Gemini key.

`gemini-gateway` and `growth-advisor` share `supabase/functions/_shared/geminiSettings.ts`. `GEMINI_API_KEY` takes precedence over the legacy server-only `GOOGLE_API_KEY` alias. Both pin `gemini-flash-latest` as requested by the owner; obsolete model environment overrides are ignored. No Google Search grounding, paid caching, priority service or model fallback is requested. Google controls whether the key’s project is Free Tier or Paid Tier; selecting a model does not change that billing status. A Gemini HTTP 402 means the linked project has no usable prepay credits, so for the requested Free Tier the key must belong to an AI Studio project marked Free Tier. Rotating the Supabase secret does not require redeploying the function. If both key names exist, rotate `GEMINI_API_KEY`; the alias will not override it. Remove obsolete `VITE_GEMINI_API_KEY` build settings. Keep JWT verification enabled for all gateways.

For a harmless live check, invoke `gemini-gateway` with a prompt such as “Reply with OK only”. Check HTTP status and sanitized error code; never return or log the key. A 503 upstream response means the provider is temporarily unavailable, not that the key was necessarily rejected. A successful model response verifies that a server-held credential works, but cannot reveal when that credential was rotated.
